# FE-01 REST Countries 평가 기준

이 기준은 [과제 지침](../task.md)과 원본 ZIP의 `data.json`을 바탕으로 한다. 원본 ZIP의 SHA-256은 manifest에 고정한다. 비교군에 같은 데이터·브라우저·검사 버전을 적용하고, 구현 에이전트의 자체 테스트 결과는 외부 판정으로 사용하지 않는다. 각 브라우저 항목은 새 페이지에서 시작한다. 화면의 시각적 품질은 사용자가 직접 판단하며 자동 점수에 넣지 않는다.

과거 이 과제는 `FE-03`이었다. 기존 `run.json`의 ID·입력 해시·스냅샷은 바꾸지 않고, 재평가할 때만 이 기준의 `FE01-*` 항목을 적용한다. 과거 Browser extensions manager와 FAQ 과제는 테스트용으로 종료했다.

## 필수 기능

| ID | 통과 조건 | 증거 |
| --- | --- | --- |
| FE01-F01 | 첫 목록에서 원본의 250개국 이름이 각각 보인다. 국가가 누락되거나 중복되지 않는다. | 원본 대비 표시 이름과 누락 목록 |
| FE01-F02 | 국가명 `Germany` 검색 결과가 Germany 하나로 좁혀진다. | 검색어·결과 목록 |
| FE01-F03 | `Asia`와 `Europe` 필터가 각각 원본 데이터의 해당 지역 국가만 보인다. | 지역별 결과 수와 이름 |
| FE01-F04 | Germany를 열면 별도 상세 화면에 국가명, 수도, 원어 이름, 하위 지역, 인구가 원본과 맞고 Back으로 목록에 돌아간다. | 상세값과 이동 전후 상태 |
| FE01-F05 | Germany 상세의 France 국경 링크를 따라가면 France 상세로 이동한다. 원본의 `borders` 코드와 대상이 맞는다. | 출발·도착 국가와 코드 |
| FE01-F06 | `Germany` 검색과 `Asia` 필터를 함께 적용하면 결과가 없고, `Europe`로 바꾸면 Germany만 보인다. 검색어를 지워도 Europe 필터가 유지된다. | 조건별 결과 목록 |
| FE01-F07 | 일치하지 않는 검색어에는 국가가 표시되지 않고, 검색어를 지우면 250개국 목록이 복구된다. | 빈 결과와 복구 목록 |
| FE01-F08 | 수도 값이 없는 Antarctica와 국경이 없는 Åland Islands 상세를 열어도 앱이 멈추지 않고 `undefined`·`null`·`NaN` 같은 데이터 오류가 표시되지 않는다. | 두 상세 화면의 텍스트와 이동 결과 |

## 접근성과 기술

| ID | 통과 조건 | 증거 |
| --- | --- | --- |
| FE01-A01 | 검색 입력, 국가 상세, Back, 국경 국가 이동을 키보드로 조작할 수 있다. 지역 필터의 키보드 조작도 확인한다. | 대상별 키 입력·이동 결과 |
| FE01-T01 | 공통 React 19·TypeScript·Vite·Tailwind CSS v4·pnpm 구성을 유지한다. | 의존성·잠금 파일·설정 |
| FE01-T02 | `pnpm install --frozen-lockfile`과 `pnpm build`가 성공한다. | 명령 종료 코드와 출력 |

기능 8개와 접근성 1개는 외부 Playwright로, 기술 2개는 도구 검사로 판정한다. 항목마다 `pass`, `fail`, `not_evaluated`, `error`와 근거를 기록한다. 인프라·검사기 오류를 구현 실패로 바꾸지 않는다. 모든 객관 항목이 판정됐을 때만 피드백용 `objective_diagnostic` 점수를 계산한다. 자동 품질의 가중치·필수 게이트는 [REQ01 계약](../../../docs/SPEC/REQ01/quality-evaluation.md)을 따른다.

## 별도 확인

- 테마 전환은 원본 과제의 선택 기능이다. 구현했다면 조작과 상태 유지를 [기능 누락 점검표](../../../evaluators/functional-review.md)에서 확인하지만, 구현하지 않았다는 이유로 필수 기능을 실패 처리하지 않는다.
- 375px·1440px의 화면 구성, 국기·타이포그래피·간격 등 시각 품질은 사용자가 직접 평가한다. 자동 점수는 시각 검토 완료를 뜻하지 않는다.
- 국가명 검색의 다른 부분 문자열, 직접 URL 열기, 연속 국경 이동 등 보완 점검은 점검표에 둔다. 자동 기준으로 추가할 때는 평가기 버전과 모든 비교군 적용 시점을 기록한다.
