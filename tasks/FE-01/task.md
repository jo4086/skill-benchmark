# REST Countries API with color theme switcher

Build the responsive country browser shown in the supplied mobile and desktop designs. Use the 250-country snapshot in `reference/data.json`; the challenge no longer relies on a live REST Countries API. Use `reference/style-guide.md`, `reference/preview.jpg`, and the images in `reference/design/` as visual references. Flag URLs in the data point to flagcdn.com.

Users should be able to:

- See all countries from the data on the home page.
- Search for a country by name and filter countries by region.
- Open a country's detailed information on a separate page and return to the list.
- Follow a border country from a detail page to that country's detail page.
- Use the app at mobile and desktop widths.

The original challenge also offers light and dark theme switching as an **optional** feature. Handle countries with missing or empty fields gracefully.

Source: [Frontend Mentor Challenges](https://www.frontendmentor.io/challenges), REST Countries API with color theme switcher challenge. The downloaded ZIP is preserved unchanged in this task package; its AI assistant guidance is excluded from the benchmark input.
