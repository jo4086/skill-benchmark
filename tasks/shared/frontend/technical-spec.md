# Benchmark frontend technical specification

Implement the task with React 19, TypeScript, Vite, and Tailwind CSS v4. Use pnpm for dependency management and scripts. Keep the provided starter assets and task requirements. Do not use a solution from the source repository or evaluation materials. You may choose the component structure, state management, and stylesheet organization.

The project is prepared with this common stack before every run. Use `pnpm install --frozen-lockfile` to install dependencies if needed, then `pnpm build` to verify the result.
