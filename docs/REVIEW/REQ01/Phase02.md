# REQ01 Phase02 검증 기록 — 자동 코드 품질 평가

## 구현 범위

- 저장된 `run.json` 하나 이상을 재평가하는 `pnpm run evaluate` 명령과 Runner의 명시적 `--evaluate-quality` 연동을 추가했다. Runner는 각 시도 직후 비교군 지침·정답·평가 자료를 뺀 `artifact/`와 SHA-256을 보존한다.
- 기존 pnpm 설치·빌드·Playwright 기능·접근성 검사에 별도의 TypeScript·ESLint 검사를 추가했다.
- Promptfoo `agent-rubric`의 고정 모델·루브릭·읽기 전용 Codex SDK 평가 경로와 구현/평가기 토큰 분리, 영역별·종합 점수를 추가했다.

## 확인한 증거

- `pnpm run test:evaluators`: 모의 `agent-rubric`의 작업 경로·읽기 전용 설정·점수와 근거, 90점 경계·필수 게이트, 저장 산출물 재평가, 토큰 분리, 지침 제외 스냅샷, 린트 실패와 기존 브라우저 검사를 확인했다.
- `pnpm run test:runner`: 새 명시적 품질 평가 옵션의 인자 검증과 기존 시도별 토큰·피드백 계약을 확인했다.
- `pnpm run test:tasks`: 수동 ZIP과 공개 과제 준비 경로를 확인했다.
- 기존 FE-02 Baseline `runs/2026-11-20T20-37-20-385Z-98ca170b-1ea5-4fac-a7d0-2dbf45194572/run.json`을 `--skip-ai`로 재평가했다. 기능 100, 접근성 100, 정적 분석 100이며 빌드·기술 사양도 통과했다. AI 점수는 `null`, 종합 점수는 `null`, 합격은 `false`로 기록했다. 결과는 Git 제외 `results/2026-11-20T21-12-20-114Z-ed2f97f7-e50c-4f1a-862a-5e19d62645c6/evaluation.json`에 있다.

## 남은 확인

시각 유사도 평가는 자동 총점 범위 밖이다. 피드백 수정 중단은 여전히 `objective_diagnostic` 기준이며 자동 품질 점수와 연결하지 않았다. FE-01의 실제 완전 평가와 목표 품질 도달 비용 비교는 남았다.

## 저장된 FE-02 결과의 실제 AI 재평가 — 2026-11-21

사용자가 승인한 기존 Codex 로그인 파일을 평가 전용 임시 홈에 권한 `0600`으로 복사했다. Codex SDK의 읽기 전용 최소 호출이 인증에 성공했다. 최초 Promptfoo 호출은 AI 코드 루브릭 버전 1이 명령을 전면 금지해 소스 열람에 실패했고, 근거 없는 0점은 평가 오류로 처리됐다. 버전 2에서 작업 폴더 안의 읽기 전용 명령만 허용해 두 저장 결과를 같은 모델·루브릭으로 다시 평가했다. 각 평가가 끝난 뒤 임시 인증 복사본과 홈을 삭제했다.

| 환경 | AI 코드 품질 | 자동 품질 총점 | 판정 | 평가기 토큰 |
| --- | ---: | ---: | --- | ---: |
| Baseline | 92/100 | 98/100 | 자동 품질 합격 | 58,642 |
| codex-workspace | 95/100 | 98.75/100 | 자동 품질 합격 | 41,944 |

두 AI 평가 모두 5개 영역에 실제 소스 파일·줄 근거를 기록했고, 원본 스냅샷 해시와 기능·접근성·정적 검사 결과를 유지했다. 평가기 토큰은 구현 토큰과 분리했다. 평가기 설정은 `gpt-6.1-sol`, 추론 `medium`, 읽기 전용 Sandbox, 승인 없음, 네트워크·검색 비활성화, AI 루브릭 버전 2다. 결과는 Git 제외 `results/2026-11-21T10-17-53-972Z-83396f0a-a150-4d52-9c30-ca25101160d6/evaluation.json`과 `results/2026-11-21T10-18-45-623Z-18f10817-6819-491d-ba2e-beb4c3480af9/evaluation.json`에 있다. 이 점수는 각 환경의 결과물 1개에 대한 자동 평가이며 시각 유사도나 반복 재현성을 입증하지 않는다.

검증 과정의 추가 사용량은 SDK 인증 최소 호출 12,192토큰과 실패한 루브릭 버전 1 AI 호출 68,952토큰이다. 두 성공 평가의 사용량 합계는 100,586토큰이며, 검증 과정 전체의 관측 토큰은 181,730이다. 이는 구현 시도의 토큰이나 실제 청구 금액이 아니다.
