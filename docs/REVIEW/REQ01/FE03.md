# FE-03 실행과 수동 피드백 기록

이 문서는 REST Countries가 과거 FE-03 ID였을 때의 실행 기록이다. 현재 과제는 [FE-01](../../../tasks/FE-01/task.md)이며, 원본 실행·수동 피드백 기록은 변경하지 않았다. 새 외부 평가 결과는 [FE-01 검증 기록](./FE01/automatic-evaluation.md)에 따로 남긴다.

[REQ01](../../REQUIREMENTS/REQ01.md)의 첫 시도·수정 시도별 측정을 FE-03에서 기록한다. 당시에는 자동 기능 평가기가 없어 이 문서에서 품질 점수와 합격 여부를 판단하지 않았다. 현재 재평가 결과는 위 FE-01 검증 기록을 따른다. 아래 `runs/`·`results/` 경로는 Git에서 제외되는 로컬 증거다.

| 환경·단계 | 실행 시간 | 비캐시 입력 | 캐시 입력 | 입력 전체 | 출력 | 총토큰 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Baseline 첫 시도 | 614,386 ms | 95,981 | 3,382,656 | 3,478,637 | 23,532 | 3,502,169 |
| codex-workspace 첫 시도 | 384,860 ms | 88,014 | 2,559,872 | 2,647,886 | 14,522 | 2,662,408 |
| codex-workspace 수동 피드백 1회 | 약 597,062 ms | 81,418 | 2,253,312 | 2,334,730 | 12,583 | 2,347,313 |
| codex-workspace 누적 | 약 981,922 ms | 169,432 | 4,813,184 | 4,982,616 | 27,105 | 5,009,721 |

입력 전체에는 캐시 입력이 포함된다. Baseline과 codex-workspace 첫 시도는 Runner에서 같은 입력 해시 `65cd275bbc4e29b183307411f855f73196c421d05c3d68f9d3bb57914a12d758`로 실행됐고, Promptfoo의 실행 완료 판정 2건이 통과했다. 두 첫 시도의 모델명은 `run.json`에 기록되지 않았다.

이후 codex-workspace 작업 폴더에서 별도 대화형 세션을 열어 UI 수정 지시를 1회 수행했다. `CountryViews.tsx`와 `styles.css`가 바뀌었고 수정 전후 데스크톱·모바일, 라이트·다크, 목록·상세 스크린샷 16장을 보존했다. 에이전트의 Playwright 로그는 검색·필터·라우팅·테마·반응형 검사가 통과했다고 보고한다. 이는 자체 검증이며 외부 Evaluator 판정이 아니다. 수동 세션은 `gpt-6.2-sol`, `workspace-write`, `on-request`로 기록돼 Runner의 `approval_policy=never`와 조건이 다르다. Baseline에는 같은 수정 기회가 없으므로 누적 토큰을 공정한 목표 품질 비용 비교로 해석할 수 없다.
