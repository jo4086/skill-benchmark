# REQ01 — 낮은 비용의 제한 검증

## 요청 배경

실제 벤치마크 전에 Runner와 피드백 흐름을 확인해야 하지만, 검증 단계에 많은 Codex 토큰을 쓸 수 없다. 검증 중에는 목표 점수를 의도적으로 낮추고 작업하면서 문서를 계속 갱신한다.

## 반영 방식

- [REQ01](../../REQUIREMENTS/REQ01.md)의 전체 품질 목표(필수 기능 100%·종합 90점)는 유지한다.
- FE-01 피드백 모드에 객관 진단 점수의 **검증용 중단 기준**을 별도로 둔다. 기본값은 50점이고 실행 옵션으로 조정할 수 있다.
- 진단 기준에 도달하면 추가 수정을 멈추되 `diagnostic_target_reached`로 기록한다. 전체 품질의 `passed`나 최초 합격 시도에 합산하지 않는다.
- 당시에는 최대 수정 횟수와 누적 토큰 예산을 함께 적용하기로 했다. 이후 [토큰 기반 중단 제거](./remove-token-stop.md) 요청에 따라 예산 중단은 폐기하고 수정 횟수 제한만 유지한다.
- 이 변경의 동작·검증 결과와 남은 조건은 REQ01, 사용 문서, 로드맵에 반영한다.
