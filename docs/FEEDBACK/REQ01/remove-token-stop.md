# REQ01 — 토큰 기반 중단 제거

## 변경 요청

작은 FE-02 과제로 제한 검증을 진행하므로 시도 사이에 토큰 사용량을 확인해 수정을 중단하는 기능은 필요하지 않다. 실제 벤치마크에도 토큰 제한을 두지 않는다.

## 반영

- [REQ01 요구사항](../../REQUIREMENTS/REQ01.md)에서 토큰 예산에 따른 중단을 제거한다.
- Runner의 `--max-total-tokens` 옵션과 `token_limit`·`usage_unknown` 중단 경로를 제거한다.
- 토큰의 시도별 증분·누적값과 측정 누락 사유는 계속 기록한다. 측정 누락도 수정 횟수와 품질 판정의 흐름을 중단하지 않는다.
- 실제 FE-02 실행 당시 사용한 70,000 설정과 첫 호출의 초과 관측값은 [Phase01 검증 기록](../../REVIEW/REQ01/Phase01.md)에 역사적 증거로 남긴다. 현재 동작의 소비 상한으로 설명하지 않는다.

앞선 [낮은 비용의 제한 검증 요청](./low-cost-validation.md)의 토큰 예산 항목은 이 변경으로 대체됐다. 낮은 진단 중단 점수와 최대 수정 횟수는 유지한다.
