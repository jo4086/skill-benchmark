# REQ01 변경 기록 — 사용자 시각 평가와 기능 누락 점검

사용자는 화면의 시각적 품질을 직접 확인한다. 외부 Evaluator에는 기존 기능·접근성·정적·AI 코드 품질 검사를 유지하고, 자동 검사가 놓칠 수 있는 기능 조합과 예외 상태를 [기능 누락 점검표](../../../evaluators/functional-review.md)로 확인할 수 있게 한다.

점검표는 과제별 평가 기준을 바꾸거나 기존 자동 점수에 새 항목을 소급 반영하지 않는다. 필수 기능의 수동 확인 결과와 시각 판단은 자동 품질 결과와 별도로 기록한다. 발견한 기능 결함을 자동 평가에 넣으려면 과제별 기준과 검사기를 같은 버전으로 모든 비교군에 적용한다.
