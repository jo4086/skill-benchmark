# REQ01 변경 요청 — 코드 품질 평가 통합

사용자 요청에 따라 기존 피드백·토큰 측정 요구사항을 확장한다. TypeScript·ESLint를 빌드와 별도 판정하고, Playwright 기능·접근성 검사를 유지한다. Promptfoo `agent-rubric`이 실제 구현 소스를 읽어 고정 루브릭으로 채점하며, 동일한 평가 조건·비교군 지침 격리·소스 변경 감지·평가 비용 분리를 적용한다. 저장된 결과 재평가 명령과 시도별 코드 스냅샷을 추가한다. 상세 기준은 [품질 평가 계약](../../SPEC/REQ01/quality-evaluation.md)이 소유한다.
