- [ ] 독립 반복과 같은 세션의 최대 두 번 피드백 수정을 구분하고 실제 Codex 세션 연결을 확인한다.
- [ ] 각 시도와 최초 목표 품질 도달 시도의 점수, 토큰 증분·누적값 및 미달 사유를 확인할 수 있다.

- [x] 외부 품질 평가에서 기능별 통과 여부와 실패 근거, 접근성, 정적 검사, AI 리뷰, 총점, 구현 시간·토큰을 Markdown으로 확인할 수 있다.
- [x] FE-01 Runner는 별도 활성화 옵션 없이 실행마다 전체 품질 평가를 수행하고 JSON·Markdown 보고서를 저장한다. Runner 테스트와 dry-run에서 기본 평가 활성화를 확인했다.
