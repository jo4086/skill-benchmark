# REQ03-Phase02 · 설치 환경과 평가기 캐시 분리

[요구사항](../../REQUIREMENTS/REQ03.md) · [로드맵](../../../ROADMAP.md) · [검증 기록](../../REVIEW/REQ03/Phase02.md)

- [x] Bootstrap, 인증 연결, Runner, 수동 실행과 비교 평가기가 저장소 밖의 같은 환경 경로를 사용한다.
- [x] 기존 환경을 자격 증명 복사와 덮어쓰기 없이 이동할 수 있고, 이동 후 환경을 검증할 수 있다.
- [x] 평가기 작업은 임시 경로에, 재사용 캐시는 사용자 캐시 경로에 생성한다.
- [x] Git 설치 환경으로 벤치마크를 시작할 때 최신 커밋을 확인하고, 사용자가 승인한 커밋을 로그인 상태를 보존하면서 다음 실행의 기본값으로 저장한다.
