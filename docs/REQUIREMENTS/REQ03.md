# REQ03 · 실행과 결과 보관

- 과제별 실행 번호로 비교군의 임시 작업 폴더와 영구 결과 폴더를 찾을 수 있다.
- 실행 기록, 자동 테스트·품질 평가와 사용자 UI 체크리스트를 실행 번호 아래에서 확인할 수 있다.
- 임시 폴더가 삭제된 뒤에도 환경별 ZIP에서 구현 결과를 복원할 수 있다. ZIP은 소스, 의존성 명세, 테스트, 문서와 환경 지침을 보존하고 인증 파일·캐시를 제외한다.
- 반복 실행과 피드백 시도별 기록을 보존한다. 기존 실행의 원시 기록과 재평가 경로를 유지한다.
