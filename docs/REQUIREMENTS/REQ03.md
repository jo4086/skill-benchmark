# REQ03 · 실행과 결과 보관

- 과제별 실행 번호로 비교군의 임시 작업 폴더와 영구 결과 폴더를 찾을 수 있다.
- 실행 기록, 자동 테스트·품질 평가와 사용자 UI 체크리스트를 실행 번호 아래에서 확인할 수 있다.
- 임시 폴더가 삭제된 뒤에도 환경별 ZIP에서 구현 결과를 복원할 수 있다. ZIP은 소스, 의존성 명세, 테스트, 문서와 환경 지침을 보존하고 인증 파일·캐시를 제외한다.
- 반복 실행과 피드백 시도별 기록을 보존한다. 기존 실행의 원시 기록과 재평가 경로를 유지한다.
- Bootstrap이 관리하는 환경과 평가기의 재사용 캐시는 저장소 외부에 둔다. 기존 환경은 인증 파일을 복사하거나 덮어쓰지 않고 이동할 수 있어야 한다.
- 모든 실행은 사용한 환경의 원본 커밋, 설치된 Skill 목록, 의도적으로 제외한 Skill 목록과 관리 콘텐츠 해시를 시도 기록과 최종 ZIP에 보존한다. 로컬 codex-workspace는 Git 저장소이면 기준 커밋과 수정 여부를 함께 기록하고, 커밋을 확인할 수 없으면 `null`을 명시한다.
