# REQ01 · 피드백 기반 품질·비용 측정

[요구사항](../docs/REQUIREMENTS/REQ01.md) · [품질 판정 계약](../docs/SPEC/REQ01/quality-evaluation.md) · [검증 기록](../docs/REVIEW/REQ01/Phase02.md)

- [ ] 독립 반복과 같은 세션의 최대 두 번 피드백 수정을 구분하고 실제 Codex 세션 연결을 확인한다.
- [ ] 각 시도와 최초 목표 품질 도달 시도의 점수, 토큰 증분·누적값 및 미달 사유를 확인할 수 있다.
- [ ] 기능과 품질의 필수 게이트를 검증하고, 객관 진단과 전체 품질 판정을 구분한다.
