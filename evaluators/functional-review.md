# FE-01 REST Countries 기능 점검표

저장된 실행 결과물을 확인할 때 [과제 평가 기준](../tasks/FE-01/evaluation/criteria.md)과 함께 사용한다. 자동 평가와 [사용자 평가 항목](../docs/REVIEW/REQ01/FE01/user-evaluation.md)은 별도 기록이다. 아래 `FE01-*` 항목의 자동 결과는 평가기 JSON에서 확인하고, 수동 보완 항목은 실제 UI 조작 결과를 적는다. 과거 `FE-03` 실행도 원본 ZIP 해시가 일치하면 새 FE-01 기준으로 재평가한다.

각 항목은 새 브라우저 상태에서 시작한다. 통과했을 때만 표시하고, 실패에는 재현 단계·기대값·실제값을 적는다. 실행할 수 없으면 `미확인`과 사유를 적는다. 기능 필수 항목 하나라도 실패하거나 미확인이면 수동 기능 확인 완료로 표시하지 않는다.

## 자동 객관 항목과 수동 확인

- [ ] `FE01-F01` 처음 목록에서 원본 `data.json`의 250개국 이름이 한 번씩 보이고 누락·중복이 없다. 국가별 국기와 핵심 데이터가 다른 국가와 섞이지 않는다.
- [ ] `FE01-F02` `Germany` 검색 결과는 Germany 하나다. 다른 부분 문자열과 대소문자 변화도 확인한다.
- [ ] `FE01-F03` `Asia`, `Europe` 필터 결과가 원본의 지역별 국가 목록과 일치한다. 전체 지역으로 되돌리면 목록이 복구된다.
- [ ] `FE01-F04` Germany 상세에서 국가명·국기·인구·지역·하위 지역·수도·원어 이름을 원본과 대조한다. Back으로 목록에 돌아온다.
- [ ] `FE01-F05` Germany의 France 국경 링크를 누르면 France 상세가 열린다. `borders` 코드와 국가 이름의 대응이 맞는지 확인하고, 연결을 한 번 더 따라간다.
- [ ] `FE01-F06` Germany 검색과 Asia 필터를 함께 적용하면 결과가 없고 Europe으로 바꾸면 Germany만 보인다. 검색어를 지우면 Europe 필터가 유지된다.
- [ ] `FE01-F07` 일치하지 않는 검색어는 빈 결과를 보이며, 검색어를 지우면 250개국이 복구된다. 빈 결과에서 앱이 멈추지 않는다.
- [ ] `FE01-F08` 수도가 없는 Antarctica와 국경이 없는 Åland Islands 상세가 열리고 `undefined`·`null`·`NaN`이 노출되지 않는다. 다른 국가의 값이 섞이지 않는다.
- [ ] `FE01-A01` Tab·Enter·Space 등으로 검색, 지역 선택, 국가 상세, Back, 국경 국가 이동을 조작한다. 현재 초점과 조작 대상이 구분되는지 확인한다.
- [ ] `FE01-T01` 공통 React 19·TypeScript·Vite·Tailwind CSS v4·pnpm 구성과 잠금 파일을 확인한다.
- [ ] `FE01-T02` `pnpm install --frozen-lockfile`과 `pnpm build` 종료 상태를 확인한다.

## 자동 검사 밖 기능 보완

- [ ] 검색어를 입력·삭제하고 필터를 바꾼 뒤 국가를 열었다가 Back으로 돌아왔을 때 목록 상태가 일관된다. 검색어·필터가 초기화되는 구현이라면 그 동작을 기록한다.
- [ ] 국가 상세에서 브라우저 뒤로·앞으로, 새로고침, 주소 직접 열기를 시험한다. URL 경로를 제공하는 구현에서는 표시 국가와 주소가 일치한다.
- [ ] 국경 국가가 여러 개인 국가에서 서로 다른 두 링크를 눌러 각각 올바른 상세로 이동한다. 국경이 없는 국가는 빈 링크나 잘못된 국가로 이어지지 않는다.
- [ ] 국가 이름에 공백·악센트가 있는 검색과 지역 변경을 조합해 잘못된 결과가 섞이지 않는지 확인한다.
- [ ] 테마 전환이 구현되어 있다면 목록과 상세에서 전환·되돌리기·탐색 중 유지가 작동한다. 테마는 선택 기능이므로 미구현만으로 필수 실패로 처리하지 않는다.

## 결과 기록

각 실행과 환경에 대해 항목 ID, 재현 단계, 기대값, 실제값, 증거 경로를 남긴다. 자동 검사 밖에서 기능 결함이 발견되면 별도 결함으로 기록하고, 모든 비교군에 같은 기준을 적용할 수 있을 때 평가기 개정을 검토한다. 사용자의 색·간격·반응형 배치 등 시각 평가는 별도로 기록하며 자동 합격으로 간주하지 않는다.
